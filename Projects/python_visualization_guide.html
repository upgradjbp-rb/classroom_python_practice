Start with the big picture

These are not three competing visualization libraries. Seaborn is built on Matplotlib; the difference is the level of abstraction and the amount of control you want.

🧰

Matplotlib pyplot

Low-level, flexible plotting commands. You explicitly control the figure, axes, labels, ticks, and plot elements.

Fine-grained control
🧭

Seaborn Figure-level

High-level functions create and manage a chart or chart grid. Faceting is a major strength for comparing groups.

Layout & faceting
🎯

Seaborn Axes-level

Statistical chart functions draw on one Matplotlib Axes. Ideal for custom layouts and combining several charts.

One axes at a time
Teaching mindset: First understand what the chart should communicate. Then choose a plotting interface. Syntax is easier to remember when it solves a visual problem.

Figure-level vs Axes-level

The most important Seaborn distinction: who creates and manages the layout, and where is the chart drawn?

Figure-level = Seaborn manages the canvas

Typically returns a grid object such as FacetGrid or PairGrid (or specialized grid classes). It creates its own figure and axes and is built to support faceting.

sns.relplot(data=df,
    x="Month", y="Sales",
    kind="line", col="Region",
    height=4, aspect=1.2)

Examples: relplot, catplot, displot, lmplot, jointplot, pairplot.

Axes-level = plot inside a chosen axes

Returns or uses a Matplotlib Axes. You can pass ax= to control where the plot appears and combine charts in a dashboard.

fig, ax = plt.subplots(figsize=(7,4))
sns.lineplot(data=df,
    x="Month", y="Sales",
    hue="Region", ax=ax)
ax.set_title("Monthly Sales")

Examples: barplot, countplot, lineplot, scatterplot, histplot, boxplot, regplot, heatmap.

01Figure size adjustment

Controls the canvas dimensions—not bar thickness, data range, or font size. Matplotlib size is in inches.

figsize=(width, height)Matplotlib figure width and height, in inches.
dpiDots per inch; affects raster resolution.
heightSeaborn figure-level height in inches.
aspectFigure-level width-to-height ratio.
Matplotlib
plt.figure(figsize=(10, 5), dpi=120)
plt.bar(categories, values)
Figure-level
sns.catplot(data=df,
    x="Category", y="Value",
    kind="bar", height=5,
    aspect=1.6)
Axes-level
fig, ax = plt.subplots(
    figsize=(10, 5), dpi=120)
sns.barplot(data=df,
    x="Category", y="Value", ax=ax)
Rule of thumb: figure-level width is approximately height × aspect. Axes-level sizing comes from the Matplotlib figure you create.

02Text, annotation & KPI card design

Add custom text anywhere in a chart. KPI cards often use axes-relative coordinates, hide axes, and layer metric, label, and comparison text.

ax.text(x, y, text)Place text at a coordinate.
transform=ax.transAxesUse relative axes coordinates from 0 to 1.
ha / vaHorizontal and vertical alignment.
bboxDraw a styled background box behind text.
Matplotlib
plt.text(0.5, 0.5, "₹12.5L",
    fontsize=24, weight="bold",
    ha="center", va="center",
    bbox=dict(boxstyle="round",
      facecolor="white", pad=.5))
Figure-level
g = sns.catplot(data=df,
    x="Category", y="Value",
    kind="bar")
g.figure.text(.5, .98,
    "Sales Overview", ha="center")
Axes-level
ax.axis("off")
ax.text(.5, .7, "TOTAL SALES",
    transform=ax.transAxes,
    ha="center")
ax.text(.5, .4, "₹12.5L",
    transform=ax.transAxes,
    fontsize=25, weight="bold")
For dashboard KPI cards: create a blank Axes, hide the axes with ax.axis("off"), and use transform=ax.transAxes so your text placement is proportional and independent of data limits.

03Chart title

A chart title describes the insight or subject. A figure-level title describes the whole grid; an axes title describes one plot.

Matplotlib
plt.title("Revenue by Month",
    fontsize=16, weight="bold",
    loc="center", pad=12)
Figure-level
g = sns.relplot(data=df,
    x="Month", y="Sales",
    kind="line", col="Region")
g.figure.suptitle("Regional trends")
g.set_titles("Region: {col_name}")
Axes-level
ax.set_title("Revenue by Month",
    fontsize=16, weight="bold",
    loc="left", pad=12)
locleft, center, right
padSpace between title and axes
fontsize / sizeTitle font size
weight / fontweightNormal, bold, etc.

04X-axis label

Names the variable represented horizontally—for example, Month, Product, Age, or Distance.

Matplotlib
plt.xlabel("Month", fontsize=12,
    labelpad=8, weight="bold")
Figure-level
g.set_axis_labels(
    "Month", "Revenue ($)")
Axes-level
ax.set_xlabel("Month",
    fontsize=12, labelpad=8,
    weight="bold")

Parameters: labelpad controls distance from the axis; fontsize changes text size; color and fontweight change appearance.

05Y-axis label

Names the vertical measurement—such as Revenue, Count, Temperature, or Salary. Units are helpful.

Matplotlib
plt.ylabel("Revenue (₹)",
    fontsize=12, labelpad=10)
Figure-level
g.set_axis_labels(
    "Month", "Revenue (₹)")
Axes-level
ax.set_ylabel("Revenue (₹)",
    fontsize=12, labelpad=10)
Label the metric and units when relevant, e.g. Revenue (₹ thousands), not simply “Revenue”.

06X-axis ticks and tick labels

Ticks are marks at specific positions. Tick labels are the text shown beside those marks. Rotate or thin crowded labels for readability.

Matplotlib
plt.xticks([0,1,2,3],
    ["Jan","Feb","Mar","Apr"],
    rotation=45, fontsize=10)
Figure-level
g.set_xticklabels(rotation=45)
# Grid object; may affect all
# facets depending on method.
Axes-level
ax.set_xticks([0,1,2,3])
ax.set_xticklabels(
    ["Jan","Feb","Mar","Apr"],
    rotation=45, ha="right")
ax.tick_params(axis="x", pad=5)
ticksPositions where marks appear.
labelsText corresponding to tick positions.
rotationRotate labels to reduce overlap.
tick_params()Length, width, direction, padding, label styling.

07Y-axis ticks and formatting

Choose meaningful intervals and format numeric values—currency, percentages, thousands separators, or decimals.

Matplotlib
plt.yticks([0, 25, 50, 75, 100])
# Format values as currency:
from matplotlib.ticker import FuncFormatter
plt.gca().yaxis.set_major_formatter(
    FuncFormatter(lambda v, pos: f"₹{v:,.0f}"))
Figure-level
g.set(yticks=[0, 25, 50, 75, 100])
# Use the underlying axes for
# advanced tick formatters.
Axes-level
ax.set_yticks([0, 25, 50, 75, 100])
ax.yaxis.set_major_formatter(
    FuncFormatter(lambda v, pos: f"₹{v:,.0f}"))

Formatter helpers: PercentFormatter (percent), MultipleLocator (regular intervals), StrMethodFormatter (format strings), FuncFormatter (custom function).

08Control data types on X and Y axes

Plotting behavior changes with the type of data: continuous numeric, category, date/time, or boolean. Seaborn usually infers the roles from DataFrame columns; Matplotlib can also handle categories and dates but is less semantic.

TypeExampleTypical visual behaviorHow to prepare
Numeric integer/floatAge, sales, scoreContinuous scalepd.to_numeric()
Categorical/stringRegion, course, genderDiscrete groupsastype("category") if useful
DatetimeOrder dateTime scalepd.to_datetime()
BooleanYes/No, True/FalseTwo groupsKeep bool or map to labels
Matplotlib
df["date"] = pd.to_datetime(df["date"])
df["sales"] = pd.to_numeric(df["sales"])
plt.plot(df["date"], df["sales"])
Figure-level
sns.relplot(data=df,
    x="date", y="sales",
    kind="line", hue="region")
# Data types and semantics inferred
Axes-level
sns.scatterplot(data=df,
    x="experience", y="salary",
    hue="department", ax=ax)
# Semantic mappings: hue, size, style
Common pitfall: numeric-looking strings such as "2", "10", "100" can be interpreted as categories. Convert to numeric if they represent a quantity. If numeric values are category codes, explicitly treat them as categorical.

09Axis range, limits and scale

Range determines which values are visible. Scale determines how values are spaced. They are different controls.

Range / limits

Zoom or frame the plot by setting the visible minimum and maximum.

plt.xlim(0, 12)
plt.ylim(0, 1000)

# Axes object
ax.set_xlim(0, 12)
ax.set_ylim(0, 1000)

Scale

Choose linear, logarithmic, or other nonlinear spacing when appropriate.

plt.yscale("linear")
plt.yscale("log")

# Axes object
ax.set_yscale("symlog")
ScaleMeaning / useImportant consideration
linearEqual value differences have equal distances.Default for most charts.
logMultiplicative differences are emphasized equally.Values must be positive.
symlogLog-like outside a linear region; handles negatives.Set a linear threshold when needed.
logitProbability-like values between 0 and 1.Endpoints 0 and 1 need special care.

Figure-level: use g.set(xlim=..., ylim=...) for simple limits; for advanced scale control, loop through g.axes.flat or use its axes. Axes-level: use ax.set_xlim(), ax.set_ylim(), and ax.set_xscale()/ax.set_yscale().

10Bar plot / vertical bars

Compare a numeric value across discrete categories. Matplotlib plots the values you provide; Seaborn barplot usually estimates (default mean) for each category and may show uncertainty intervals.

Concept: categories on X; measured values on Y.

Matplotlib · plt.bar
plt.bar(categories, values,
    width=.7, color="steelblue",
    edgecolor="white", alpha=.9)
Figure-level · catplot
sns.catplot(data=df,
    x="Category", y="Sales",
    kind="bar", height=4,
    aspect=1.4, errorbar=None)
Axes-level · barplot
sns.barplot(data=df,
    x="Category", y="Sales",
    estimator="mean",
    errorbar=("ci", 95), ax=ax)
widthMatplotlib bar width.
color / paletteFill color or color mapping.
estimatorSeaborn aggregation (mean by default).
errorbarUncertainty interval; use None to hide.
hueSplit category bars by a second group.
orderControl category order.
Do not confuse barplot and countplot: barplot summarizes a numeric variable by category (usually mean); countplot counts how many rows fall into each category.

11Horizontal bar plot

A bar chart turned sideways. Especially helpful for long category labels, ranked lists, and Top-N comparisons.

Matplotlib · barh
plt.barh(categories, values,
    height=.65, color="coral")
plt.gca().invert_yaxis() # optional:
# highest rank at top, if sorted
Figure-level
sns.catplot(data=df,
    y="Category", x="Sales",
    kind="bar", aspect=1.5)
# Swap category and value axes
Axes-level
sns.barplot(data=df,
    y="Category", x="Sales",
    orient="h", ax=ax)
# Orientation may be inferred

Parameters: Matplotlib barh(y, width, height, left); Seaborn use category on y, numeric value on x, and optionally order for ranking.

12Line chart

Shows change over an ordered dimension—often time. It helps spot trend, peaks, dips, seasonality, and compare series.

Matplotlib
plt.plot(x, y, color="teal",
    linewidth=2, marker="o",
    linestyle="-")
Figure-level · relplot
sns.relplot(data=df,
    x="Date", y="Sales",
    kind="line", hue="Region",
    style="Region", markers=True)
Axes-level · lineplot
sns.lineplot(data=df,
    x="Date", y="Sales",
    hue="Region", markers=True,
    estimator="mean", errorbar=None,
    ax=ax)
linewidth / lwLine thickness.
markerMarker symbol at observations.
linestyleSolid, dashed, dotted etc.
hue / styleGroup colors and line/marker styles.
estimatorSeaborn aggregation when repeated x-values occur.
errorbarUncertainty around estimate.
A line implies an ordered relationship. Connecting unordered categories may mislead; if category order matters, set it explicitly.

14Pie chart

Shows part-to-whole composition. Use a small number of slices and consider a bar chart if close values must be compared precisely.

Matplotlib
plt.pie(values, labels=labels,
    autopct="%1.1f%%", startangle=90,
    explode=[0, .05, 0],
    wedgeprops={"edgecolor":"white"})
plt.axis("equal")
Seaborn figure-level
# No dedicated figure-level
# pie chart function.
# Create a figure and use
# Matplotlib pie instead.
Seaborn axes-level
fig, ax = plt.subplots()
ax.pie(values, labels=labels,
    autopct="%1.1f%%",
    startangle=90)
ax.set_aspect("equal")
autopctFormat for percentages.
startangleRotate the first slice start.
explodeOffset selected slices.
wedgepropsStyle slice borders and width.
pctdistancePosition percentage labels.
labeldistancePosition category labels.
Pie charts are not part of Seaborn's native chart API. Axes.pie() is a Matplotlib function, even when you use a Seaborn-themed figure.

15Histogram

Groups numeric observations into intervals (bins) and shows how many observations fall in each interval. Use it to understand distribution shape.

Unlike a bar chart, the bars represent intervals of a continuous numeric variable. Adjacent bars typically touch.

Matplotlib
plt.hist(values, bins=10,
    density=False, cumulative=False,
    edgecolor="white", alpha=.85)
Figure-level · displot
sns.displot(data=df, x="Age",
    kind="hist", bins=10,
    kde=True, hue="Group",
    height=4, aspect=1.4)
Axes-level · histplot
sns.histplot(data=df, x="Age",
    bins=10, binwidth=5,
    stat="count", kde=True,
    hue="Group", ax=ax)
bins / binwidthNumber of bins or bin size.
range / binrangeLimit the binning region.
density / statCount, probability, density, etc.
cumulativeAccumulated distribution.
kdeOverlay a smooth density estimate.
multipleLayer, stack, dodge, or fill hue distributions.
Histogram question: “How are numeric values distributed?” Bar-chart question: “How do categories compare?”

16Box plot

Compact statistical summary of a numeric distribution: median, quartiles, whiskers, and potential outliers.

Matplotlib
plt.boxplot(values,
    vert=True, patch_artist=True,
    showmeans=True, showfliers=True,
    whis=1.5)
Figure-level · catplot
sns.catplot(data=df,
    x="Department", y="Salary",
    kind="box", hue="Gender",
    height=4, aspect=1.4)
Axes-level · boxplot
sns.boxplot(data=df,
    x="Department", y="Salary",
    hue="Gender", showmeans=True,
    whis=1.5, ax=ax)
whisWhisker rule, often 1.5× IQR.
showfliersShow outlier markers.
showmeansShow mean marker.
notchNotched median interval in Matplotlib.
orderCategory ordering.
widthWidth of boxes.

Interpretation: The box covers the middle 50% (IQR = Q3 − Q1). Whiskers are determined by the whisker rule, not necessarily the absolute minimum and maximum. Points beyond whiskers are potential outliers—not automatically errors.

17Area chart

Fill the region under a line to emphasize magnitude. Stacked area charts show how multiple components contribute to a total across time.

Matplotlib
plt.fill_between(x, y,
    color="skyblue", alpha=.35)
plt.plot(x, y, color="steelblue")

# Stacked area
plt.stackplot(x, y_a, y_b, y_c,
    labels=["A", "B", "C"])
plt.legend()
Figure-level
# No native area chart API.
# Make the grid/figure as desired,
# then use Matplotlib fill functions
# on its axes.
Axes-level
sns.lineplot(data=df,
    x="Date", y="Sales", ax=ax)
ax.fill_between(df["Date"],
    df["Sales"], alpha=.25)
# Or ax.stackplot(...) for stacks
whereConditionally fill regions.
alphaTransparency.
interpolateInterpolate at condition boundaries.
baselineStackplot baseline style.
Area charts can obscure overlapping series. Consider a line chart when the goal is comparing separate trends, and stacked area when the total and composition matter.

18Count plot (frequency plot)

Counts the number of records in each category automatically. It is a categorical frequency chart—not a histogram.

Matplotlib
counts = df["Course"].value_counts()
plt.bar(counts.index,
    counts.values)
Figure-level · catplot
sns.catplot(data=df,
    x="Course", kind="count",
    hue="Group", height=4,
    aspect=1.4)
Axes-level · countplot
sns.countplot(data=df,
    x="Course", hue="Group",
    order=["Python","SQL","Excel"],
    ax=ax)
x / yCategory being counted.
hueCounts split by a second category.
orderControl category order.
statCount/proportion/percent modes supported by installed version.
paletteColor scheme.
dodgeSeparate hue bars side by side.
Matplotlib workflow: value_counts() first, then plot the counts with plt.bar(). Seaborn countplot() does that counting step for you.

19Trend line / regression

A fitted line summarizes a relationship. It can reveal an overall direction amid noisy points. Correlation or regression alone does not prove cause and effect.

Matplotlib + NumPy
m, b = np.polyfit(x, y, 1)
trend = m * x + b
plt.scatter(x, y)
plt.plot(x, trend, color="red")
Figure-level · lmplot
sns.lmplot(data=df,
    x="Experience", y="Salary",
    hue="Department", ci=95,
    order=1)
Axes-level · regplot
sns.regplot(data=df,
    x="Experience", y="Salary",
    ci=95, order=1,
    line_kws={"color":"red"}, ax=ax)
orderPolynomial degree for fitted curve.
ciConfidence interval; use None to hide.
robustRobust regression option in applicable API.
lowessLocally weighted smoother.
logisticLogistic model option in applicable API.
scatterShow or hide observations.
Figure-level lmplot() supports grouping/faceting such as hue, col, and row. Axes-level regplot() is designed for a single Axes and does not provide the same faceting interface.

20Heatmap

Encodes values in a grid using color. Common examples include correlation matrices, pivot tables, cross-tabulations, and confusion matrices.

Color intensity represents the value. Read the legend (color bar) to know the scale.

Matplotlib · imshow
plt.imshow(matrix,
    cmap="coolwarm", aspect="auto",
    vmin=-1, vmax=1)
plt.colorbar()
Figure-level
# No dedicated figure-level
# heatmap function in Seaborn.
# Use figure/axes setup and then
# sns.heatmap() on an Axes.
Axes-level · heatmap
sns.heatmap(matrix, annot=True,
    fmt=".2f", cmap="coolwarm",
    center=0, vmin=-1, vmax=1,
    linewidths=.5, cbar=True, ax=ax)
annotWrite values in each cell.
fmtNumber formatting for annotations.
cmapColor map.
vmin / vmax / centerSet color normalization range/center.
maskHide selected cells.
cbarShow the color legend.
linewidths / linecolorCell grid lines.
squareSquare cell shape.
Correlation matrix: corr = df.select_dtypes(include="number").corr(), then plot sns.heatmap(corr, annot=True, cmap="coolwarm", center=0, vmin=-1, vmax=1). A correlation value near +1 means strong positive linear association, near −1 strong negative association, and near 0 little linear association.
